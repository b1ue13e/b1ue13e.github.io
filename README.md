# Junyu Li — Personal research website

Live site: [b1ue13e.github.io](https://b1ue13e.github.io/)

A bilingual personal website about my research in machine learning, sequential decision-making, and optimization.

The website uses plain HTML, CSS, and JavaScript. Serve this directory with a static web server to preview it:

```sh
python -m http.server 8080
```

Content is in `index.html`, with Chinese translations in `content.js`. Interactions are in `site.js`, and visual styles in `styles.css`. GitHub Pages publishes the `main` branch root directly.
